# 2026-11-03 Console2全局字号与阅读密度调整

用户指出实时监测流向表难读，并明确这是全局问题。旧styles.css/full.css存在大量5–10px字号，实时流向表头6px、行文字7px。此次按运营工作台阅读尺度统一修正，不依赖浏览器放大或整页缩放。

## 统一规则

- styles.css定义rem token：正文/表格14px、辅助说明/图表刻度12px、区块标题16px；root为16px。保留已有大号关键数值。
- 全局两份样式中的小字号使用同一token；Recharts在实时监测、研判、集成、系统页面的内联10px刻度改12px，提示框同样至少12px。
- readability.css负责与字号匹配的行高、表格换行、36px表单/操作控件、卡片尺寸和面板滚动。表格长标识/描述可换行，数据不因放大而丢弃。
- 监测左栏380–420px，右栏330–380px，流向行高至少42px，正文14px；表头/单位12px。顶部态势栏和检测状态条分开定位。右侧事件列表保留至少160px，并允许滚动访问证据/操作。
- 加强监测浮层底色以承载放大后的文字，保留现有暗色风格、导航、检测主视图、BEV及收缩/锁定操作。

## 验证

- Console2 `npm test`：25文件、284测试通过；`npm run build`通过；`git diff --check`通过。
- 1333×902真实登录页面验证：监测流向行14px/表头12px，事件、测绘、无人机和系统页表格14px；可见main叶节点文本未检出小于12px，根文档无水平溢出。地图SDK iframe及检测视频中烘焙文字不属于CSS字号检查。
- 1366×768、1920×1080监测布局检查：根文档无水平溢出，顶部态势栏与检测状态条不重叠，左右栏在视口内。列表/长面板通过滚动查看，未为塞满单屏重新缩字。
- 浏览器截图与尺寸/字号采样位于`output/playwright/typography-*`。其中`typography-page-checks-loaded.txt`记录已加载列表页，`typography-live-viewport-checks.txt`记录真实监测多尺寸结果。

本轮只改Console2表现层及协作说明，不改检测、统计、鉴权、消息或数据库。此前FPS问题仍按独立排查报告保留，字号修改不代表其性能结论变化。
