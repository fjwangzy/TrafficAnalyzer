| 项目 | 内容 |
| --- | --- |
| 文档定位 | 无人机交通智能感知系统总 PRD 的 S2 业务分册 |
| 版本/日期 | v0.2 / 2026-07-13 |
| 评审对象 | 指挥中心、交安专家、算法、测试、路网数据方、智慧交通主平台方 |
| 当前状态 | 可进入需求评审；算法阈值、验收集和主平台契约待冻结 |

> 本分册定义换道、潜在冲突和风险热区的 AI 识别与标准化输出，不直接认定事故责任、交通违法或警情等级，不负责派警、处置和归档。总 PRD 与本分册冲突时，以合同/澄清文件和已批准总 PRD 为准。
## 1. 目标、交付结果与非目标
### 1.1 目标
1. 在有效无人机监测窗口内识别可复核的车辆换道事件。
2. 识别机动车、非机动车和行人相关的潜在时空冲突，输出 TTC、PET、最小距离、冲突角、预测轨迹和风险等级。
3. 将事件关联到权威路口、Link、车道和路网版本，低质量时明确降级，不伪造主数据 ID。
4. 聚合经分层统计的风险热区，并可追溯至原始事件、算法版本和聚合参数。
5. 将事件可靠投递智慧交通主平台，接收 AI 结果确认或驳回反馈。
### 1.2 非目标与责任边界
- 不建设主平台的警情合并、指挥调度、派警签收、到场处置和解除归档流程。
- 不将 AI 的 high/medium/low 直接解释为主平台 P1/P2/P3。
- 不将换道事件直接解释为违法变道，不自动认定事故责任。
- 不承诺无人机未执行任务、画面无效或数据质量不满足条件时的持续监测。
- 不在本分册自行扩大参与者组合；最终冲突对象矩阵见 S2-TBD-005。
### 1.3 现状与目标能力分界
| 能力 | 现状判断 | 本分册目标 |
| --- | --- | --- |
| 检测、ByteTrack 跟踪、ENU 世界坐标、运动补偿 | 已有共性基础能力，不等于 S2 已验收 | 作为输入并增加质量门禁 |
| 机非冲突 | 已有 motor 与 non_motor 轨迹对的基础路径交点/TTC near-miss 能力 | 扩充为版本化、可复核的目标事件契约 |
| PET | 现有字段是预测到达时间差近似，不能直接视为严格观测 PET 已完成 | 区分预测 PET 与观测 PET，按冻结口径验收 |
| 换道识别 | 目标新增能力 | 建设车道归属、跨界和横向运动双重验证 |
| 3–5 秒预测 | 当前为运动学外推基础方案 | 按统一数据集验收；合同偏差未关闭 |
| 风险三级与热区 | 规则/方案草案 | 建设可配置分级和可追溯聚类，阈值待确认 |
| 主平台联动 | 目标契约草案，尚非正式接口 | 完成幂等、回执、重试和复核反馈联调 |
### 1.4 投标符合性门禁
投标方案要求 LSTM + 时序卡尔曼实现 3–5 秒预测；当前工程方案为运动学外推 + 卡尔曼。S2-TBD-001 未取得甲方书面变更，或未在同一验收集上以 ADE/FDE、碰撞点误差、事件质量、时延和资源占用证明等效并获书面批准前，不得宣称该条款符合、不得删除学习型预测合同范围，也不得以“当前已实现”替代验收结论。

## 3. 前置条件、输入与输出
### 3.1 运行前置条件
1. 任务携带唯一 task_id、权威 inter_id 和冻结的 road_data_version。
2. 视频帧与遥测使用可追溯时间基准；漂移超过阈值时暂停确定性指标输出。
3. TTC、PET、距离和角度计算须有有效单应性、米级世界坐标和运动补偿质量。
4. 正式换道事件须有可用视觉车道和稳定的起止车道归属；权威 lane_id 不可用时不得拼造。
5. 参与者检测类别、轨迹长度和速度向量满足对应算法最低要求。
### 3.2 输入
| 输入 | 必要内容 | 质量要求 |
| --- | --- | --- |
| 视频与时间 | 帧、frame timestamp、camera/device ID | 连续性、时钟状态可追溯 |
| 无人机遥测 | GPS/RTK、姿态、云台、飞行高度 | 新鲜度和定位质量可判断 |
| 目标轨迹 | track ID、类别、框、像素/ENU 轨迹、速度、加速度 | ID 连续、历史长度足够 |
| 标定与补偿 | 单应性、世界锚点、无人机位移 | 有效性和误差状态明确 |
| 路网与视觉车道 | inter/link/lane、拓扑、车道多边形、版本、绑定置信度 | 只读已发布快照；版本冻结 |
| 规则配置 | 阈值、场景、风险和聚类参数 | 有版本、审批人和生效期 |
### 3.3 输出
- `uav_ai_events`（`event_type=lane_change`）：换道前后车道、横向运动、起止时间、质量和证据引用。
- `uav_ai_events`（`event_type=conflict`）：目标对、场景、TTC/PET/最小距离/角度、预测轨迹、风险和证据。
- `uav_ai_events`（`event_type=risk_hotspot`）：空间范围、统计窗口、分层事件数、风险摘要、聚类参数和样本引用。
- diagnostics：跳过原因、质量状态、覆盖时长、模型/规则/路网版本。
## 4. 主业务流程
### 4.1 换道识别
1. 将目标位置投影到车道中心线局部坐标，形成逐帧车道归属和横向位移序列。
2. 使用稳定窗口抑制边界抖动；发现从车道 A 向相邻车道 B 跨界时生成内部候选。
3. 同时校验几何跨界、持续横向运动、前后车道稳定驻留和车道拓扑合理性。
4. 排除 ID 切换、遮挡跳点、道路合流/分流、正常转向和标定漂移造成的伪换道。
5. 候选满足冻结规则后生成事件并保存证据；否则仅记录诊断，不上送正式事件。
### 4.2 冲突识别
1. 按参与者类型、空间邻域和时间窗生成目标对候选。
2. 在统一 ENU 坐标和同一时间基准上预测 3–5 秒轨迹。
3. 求路径冲突区、同步最近距离、双方到达时间和冲突角，并判断指标有效性。
4. 结合急减速、避险转向、停车/让行等证据过滤仅有数学交点的误报。
5. 使用版本化规则输出风险等级、置信度和证据；质量不足时跳过或降级。
6. 同一事件只更新版本或在风险升级时重发，避免逐帧重复告警。
### 4.3 风险热区与主平台联动
1. 分别聚合全部候选、AI 正式事件、人工确认和人工驳回事件，禁止混用分母。
2. 优先按 inter_id/link_id/lane_id 聚合；无法可靠地图匹配时可按 GCJ02 空间单元聚合，但主数据 ID 为空。
3. 生成事件后依次进入 generated、delivering、delivered 或 delivery_failed；主平台复核后记录 reviewed_confirmed/reviewed_rejected。
4. 子项目只保存平台事件映射和复核反馈，不维护派警处置状态。

## 6. 指标与业务规则口径
### 6.1 换道
- 车道归属以视觉车道多边形和经确认的主数据绑定为准；local lane key 不能冒充权威 lane_id。
- 正式换道必须同时满足几何跨界和横向运动证据，且从/到车道具有稳定驻留；持续帧数、位移和速度阈值见 S2-TBD-002。
- 沿拓扑正常进入转向车道、合流/分流或车道几何终止，不默认判为换道；具体规则见 S2-TBD-009。
- 换道只是行为事件；是否压实线或违法需额外道路标线、规则和法制口径，不属于本分册自动结论。
### 6.2 TTC、PET、最小距离、冲突角和预测
- TTC：从评估时刻起，预测双方安全包络首次发生时空重叠的最早未来时间；无碰撞趋势或超出预测时域时为空。实现必须记录 metric_method_version。
- 预测 PET：双方预计通过同一冲突区的到达/离开时间间隔；只用于实时预警。
- 观测 PET：第一参与者实际离开冲突区至第二参与者实际进入的时间差；轨迹未完整通过前为空。现有到达时间差近似不得无标记冒充观测 PET。
- 最小距离：共同预测时域内同步位置的最小距离；须标记 center_point 或 object_envelope 口径。
- 冲突角：冲突时刻两速度方向的较小夹角，范围 0–180°；任一速度低于有效阈值时为空。
- 预测轨迹须输出 prediction_method、prediction_horizon_sec、采样间隔、模型版本和质量；缺历史时可降级，但不得隐藏降级。

当前实现文档中的到达容差 1.0 秒、共同冲突半径 0.8 米、冲突角 30°–150°、hard TTC 1.5 秒、hard PET 1.0 秒和急减速 -3.0m/s²，仅是现有配置基线，不是本项目验收阈值。总 PRD 中 TTC 三级区间及 DBSCAN 最小事件数 3、半径 50 米同样属于待确认草案，统一由 S2-TBD-002/003 关闭。
### 6.3 风险与热区
- 风险等级必须由原始指标、避险证据、场景、数据质量和规则版本共同解释；PET 单一指标不得在未冻结规则时直接生成高风险结论。
- same_time_cpa 可作为扩展候选，但现有业务展示只接受有效 path_intersection；CPA-only 事件不得混入正式冲突统计。
- 合同验收路径保持 DBSCAN 空间聚类；路段/网格聚合只能作为附加展示或预聚合方式，不能替代 DBSCAN 交付。若需用其他算法替代，必须取得书面变更。空间尺度、窗口、最小样本和置信规则未冻结前不得承诺固定参数。
- 热区必须展示有效监测时长和样本基数，避免将无人机间歇覆盖解释为全天风险。
## 7. 事件标识、去重和状态

- source_event_id 在同一次识别事件内稳定；idempotency_key 在重试时保持不变。
- 冲突同源键至少包含 task、无序目标对、事件片段和算法版本；换道同源键至少包含 task、track、from/to lane 和片段。
- 同一目标对同等级事件不逐帧重复上报；风险升级可产生新 revision 并重发，指标更新保留历史版本。
- 跟踪 ID 只能在 task 范围内解释；跨无人机、跨任务、跨感知源合并由智慧交通主平台负责。
- 投递状态严格使用 generated/delivering/delivered/delivery_failed；复核结果使用 reviewed_confirmed/reviewed_rejected，均不包含派警状态。
## 8. 目标字段契约

> 以下为待 S6 冻结的目标契约。实时冲突兼容源将迁移至 <code>uav_conflicts_{camera_id}</code>（<code>msg_type=uav_conflict</code>），跨场景业务事件统一进入 <code>uav_ai_events</code>（<code>msg_type=uav_ai_event</code>）；这不代表当前代码已全部实现目标契约。

目标持久化位于 database=`road9`：时序冲突事实写 `uav_conflict_events`，需要跨系统交付的换道/冲突/热区事件写 `uav_ai_events` 与 `uav_event_outbox`，每次投递写 `uav_event_delivery_attempts`；`source_system` 固定为 `uav_traffic_analyzer_ai`。场景详情可以使用通用 payload 或经 DDL 评审冻结的详情投影，但不得再建第二套事件主表。

## 9. 页面与交互

1. 实时监测：叠加目标轨迹、预测轨迹、冲突点、风险等级、覆盖和质量状态。
2. 事件列表：按类型、风险、路口、Link/车道、时间、复核和投递状态筛选。
3. 事件详情：同步视频/BEV 回放，展示原始指标、规则版本、质量原因、证据和状态时间线。
4. 风险热区：切换候选/正式/确认/驳回图层，展示统计窗口、有效覆盖和样本数。
5. 运维视图：展示跳过原因、未映射率、延迟、重试、死信和版本分布。

页面不得用当前播放位置替代预测冲突点，不得把 AI 复核状态展示成警情处置完成。
## 10. 异常与降级

| 异常 | 行为 |
| --- | --- |
| 无有效单应性/世界坐标 | 不输出确定性 TTC/PET/距离事件，记录 skip reason |
| 遥测中断或运动补偿不可信 | 按总 PRD 降级；超过门槛暂停世界坐标指标 |
| 路网缓存 stale | 可继续冲突分析并标记 stale；换道仅在视觉车道仍可靠时输出，本地 ID 不冒充权威 ID |
| 路网缺失/版本不符 | 主数据字段为空并标记 unmapped/version_mismatch |
| 轨迹过短、ID 切换或遮挡跳点 | 隔离候选，满足重新稳定条件后再评估 |
| 低速/静止导致 TTC 无效 | TTC 为空，可使用已冻结的 PET/让行规则，禁止以零值代替 |
| 时间不同步 | 暂停跨目标时序指标并告警 |
| 推理过载 | 按配置降帧并记录有效覆盖，不能静默降低统计分母 |
| 主平台断连 | 持久化出站、指数退避、恢复重传；超限进入死信并告警 |

## 12. 数据标注与验收集

- 标注单元：完整轨迹、换道片段、冲突目标对、冲突区、避险行为和困难负样本。
- 换道标签：track、from/to lane、开始/跨界/完成时间、是否合流分流、可见性和标注置信度。
- 冲突标签：参与者类型、场景、冲突区、双方进入/离开时间、最小距离、冲突角、避险行为及正负结论。
- 困难负样本必须覆盖正常转向、并行擦肩、排队低速、遮挡 ID 切换、无人机漂移、数学交点但不同步通过。
- 按路口和日期切分训练/验证/验收集，禁止同一连续轨迹跨集合泄漏；白天/夜间、天气、高度、视角和参与者组合分层统计。
- 双人独立标注、专家仲裁并记录版本；样本量、匹配窗和一致性阈值见 S2-TBD-004。
## 13. 分层验收指标与用例
### 13.1 指标
| 层级 | 指标 |
| --- | --- |
| 数据基础 | 时间同步误差、米制坐标误差、车道绑定准确率、有效覆盖率、unmapped 率 |
| 换道 | Precision/Recall/F1、from/to lane 准确率、起止时间误差、单位小时误报 |
| 冲突 | 按对象组合/场景的 Precision/Recall/F1、漏报率、单位小时误报、事件时间/位置误差 |
| 物理指标 | TTC/PET/最小距离/冲突角误差、有效输出覆盖率和无效值正确率 |
| 预测 | 1/3/5 秒 ADE/FDE、碰撞点误差、有效预测覆盖率、时延和资源占用 |
| 风险/热区 | 专家一致性、分级混淆矩阵、事件可追溯率、聚类稳定性和最小样本可信度 |
| 集成 | schema 校验、幂等、升级、重试、死信、回执和复核反馈 |

总 PRD 的上线三个月安全事件 Precision ≥85% 是成功目标，不代替验收时必须同时冻结的 Recall 和单位小时误报上限。
### 13.2 核心验收用例
